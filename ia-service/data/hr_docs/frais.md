# Notes de frais

## Dépenses remboursables
Les frais professionnels remboursables incluent les déplacements, l'hébergement,
les repas lors de déplacements et le matériel validé par le responsable. Chaque
dépense doit être justifiée par un reçu ou une facture.

## Plafonds
Les repas sont remboursés jusqu'à 20 euros par repas en déplacement. L'hébergement
est remboursé sur la base du tarif réel sur présentation de facture. Les
déplacements en train sont privilégiés pour les trajets de plus de 300 kilomètres.

## Délai de soumission
Une note de frais doit être soumise dans le mois suivant la dépense. Passé ce
délai, le remboursement peut être refusé par le service financier.

## Validation
La note de frais est validée par le responsable hiérarchique puis transmise au
service financier pour paiement. Le remboursement intervient sur la paie du mois
suivant la validation.
